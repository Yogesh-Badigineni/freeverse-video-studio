# Changelog

All notable changes to FreeVerse Video Studio will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-23

### Added
- **Natural & Pro Video Editing**: Multi-clip video and image arrangement, scene durations, transitions, and export presets.
- **Smart Storyboard Engine**: Natural language prompt to multi-scene video plan with procedural styled visual cards.
- **Kids' Cartoons & Stories**: Family-friendly workflow with 2D bouncy camera animations and child-safe content filtering.
- **Educational Explainer Ingestion**: Ingest TXT and Markdown files to extract key concepts, bullet slides, and narration scripts.
- **Social Media Shorts (9:16)**: Built-in vertical video presets with 3-second hook structure.
- **Audio Mixing & Narration**: Multi-track audio mixer with volume sliders, fade in/out, voiceover recorder, speech synthesis, and smart auto-ducking.
- **FFmpeg 7.1 Static Rendering**: Real MP4 video composition with H.264 video and AAC audio encoding.
- **Local AI Model Hub**: Diagnostics and integration checks for Ollama, ComfyUI, Piper TTS, and Faster-Whisper.
- **Security Hardening**: Safe subprocess execution (`shell=False`), path traversal defense (`resolve_safe_path`), strict MIME validation, and loopback binding (`127.0.0.1`).
- **One-Click Launchers**: `run_studio.bat`, `run_studio.ps1`, and `start_studio.py`.
- **Public Showcase Website**: Fully responsive documentation and feature showcase site.
